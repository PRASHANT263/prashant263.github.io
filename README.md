# prashant263.github.io

My portfolio, live at **https://prashant263.github.io**. It's generated by a small static site generator written in Go and deployed to GitHub Pages by GitHub Actions.

```bash
go run ./cmd/serve    # http://localhost:8080, rebuilds on every save
go run ./cmd/build    # writes dist/
go test ./...
```

To put it online from scratch, follow **[DEPLOY.md](DEPLOY.md)**.

## Editing content

Everything lives in `content/` and `static/`. No code changes needed:

| To… | Edit |
|---|---|
| Add a blog link | `content/blog.yaml` (example inside) |
| Update the resume | replace `static/resume.pdf`, regenerate `static/img/resume-preview.png` (see DEPLOY.md), bump `resume_updated` in `content/profile.yaml` |
| Change the photo | replace `static/img/profile.jpeg` (portrait 4:5) |
| Headline, pitch, About cards, skill bubbles, socials, contact form | `content/profile.yaml` |
| Experience timeline | `content/experience.yaml` |
| Skills | `content/skills.yaml` |
| Side projects | `content/projects.yaml` |
| Awards and milestones | `content/recognition.yaml` |
| Add a case study | new `content/case-studies/<slug>.md` with front matter |

The build stops on any content mistake and names the file and field.

## Layout

- `internal/content`: domain types, loading, validation (no HTML)
- `internal/render`: templates and Markdown to HTML (no disk writes)
- `internal/site`: builds `dist/`, copies static files, checks links
- `cmd/build`, `cmd/serve`: entry points
- `templates/`, `static/`: HTML templates, CSS, JS, fonts and images
